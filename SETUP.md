# Как развернуть AeroPulse у себя и показать на защите

Инструкция для Windows 10/11. Если идти по шагам, всё займёт около 15 минут вашего времени
и 2–3 часа ожидания, пока загружается история (или 3 минуты, если взять готовую базу — вариант Б).

---

## 0. Что понадобится

| Что | Где взять | Как проверить, что уже есть |
|---|---|---|
| **Python 3.12 или новее** (проверено на 3.14) | https://www.python.org/downloads/ — при установке **поставить галочку «Add python.exe to PATH»** | `py --version` в терминале → `Python 3.1x.x` |
| **Git** | https://git-scm.com/download/win — всё по умолчанию | `git --version` |
| ~2 ГБ на диске | история рейсов за 4 года: ~1,5 ГБ ZIP-файлов + база ~0,5 ГБ | — |
| Интернет | сайты `transtats.bts.gov`, `mesonet.agron.iastate.edu`, `open-meteo.com` | см. раздел «Если что-то пошло не так» |

Терминал — это «Командная строка» (Win+R → `cmd`) или PowerShell. Все команды ниже работают в обоих.

---

## 1. Склонировать репозиторий

Перейдите в папку, где будет лежать проект (лучше путь **без пробелов**, например `C:\projects`):

```bat
cd C:\projects
git clone https://github.com/BuyBuy-Service/teterin.git aeropulse
cd aeropulse
```

Если git попросит логин — войдите в свой GitHub-аккаунт (у вас есть доступ к организации `BuyBuy-Service`).

---

## 2. Первый запуск

Есть два варианта: загрузить историю самому (долго, но «честно») или взять готовую базу у Харлашкиной А.В. или Селивановой А.К. (быстро).

### Вариант А — загрузить всё самому (2–3 часа)

```bat
run.bat
```

Что произойдёт:
1. Создастся виртуальное окружение `.venv` и поставятся библиотеки (1–3 минуты).
2. Загрузится история: 48 месяцев рейсов BTS (самое долгое — 2–5 минут на месяц, сайт BTS медленный), METAR по ORD
   и 10 аэропортам сети за 4 года, прогноз погоды.
   На экране идут строки вида `BTS 2025-03: строк 62746, новых 62746` — это нормально.
3. Посчитаются витрина, модель и проверки качества (~20 секунд).
4. Откроется браузер с дашбордом: http://localhost:8501

Окно терминала **не закрывайте** — в нём работает дашборд. Остановить: Ctrl+C в этом окне.

### Вариант Б — взять готовую базу (~3 минуты) — рекомендуется — рекомендуется

1. Попросите у Харлашкиной А.В. или Селивановой А.К. файл `data\aeropulse.db` (~0,5 ГБ — через облако/флешку).
2. Положите его в папку проекта по пути `aeropulse\data\aeropulse.db` (папку `data` создайте сами).
3. Запустите `run.bat` — он догрузит только то, что появилось с момента их последнего запуска (секунды),
   и откроет дашборд.

> Сырые ZIP-файлы BTS при этом не копируются — они не нужны для работы. Если на защите спросят «где сырые данные» —
> они в таблице `raw_files` (путь и хэш каждого файла) и у того, кто грузил историю, в `data\raw\bts`.

## 3. Проверить, что всё работает

На странице **«Журнал и качество»**:
- у всех узлов схемы зелёная рамка;
- в журнале последние запуски со статусом ✅ `success`;
- в карточках сверху: BTS — `2026-08` (или новее), METAR — сегодняшняя дата;
- на странице «Погода и задержки» есть карта «аэропорт × день» для 10 аэропортов сети.

На странице **«Прогноз»** — график на 7 дней вперёд, начиная с сегодня.

Дополнительно можно прогнать тесты (должно быть `48 passed`):

```bat
.venv\Scripts\python -m pytest -q
```

## 4. Повседневные команды

| Что нужно | Команда |
|---|---|
| Обновить данные и открыть дашборд | `run.bat` |
| Открыть дашборд без обновления (быстро) | `run.bat skip` |
| Только обновить данные | `update.bat` |
| Обновлять каждый час автоматически | `schedule_install.bat` (удалить: `schtasks /Delete /TN "AeroPulse update" /F`) |
| Вся цепочка вручную | `.venv\Scripts\python pipeline.py` |
| Отдельные шаги | `.venv\Scripts\python pipeline.py --only metar openmeteo` |

## 5. Подготовка к защите (чек-лист)

**За день:**
- [ ] `git pull` — забрать последние изменения.
- [ ] `run.bat` — данные обновятся до сегодняшнего дня. Проверить страницы по разделу 3.
- [ ] Пройти сценарий `docs/demo-script.md` целиком хотя бы раз.
- [ ] Презентация — `report/Презентация_AeroPulse.pptx`, в заметках к слайдам написано, кто что говорит. Держать открытой рядом с дашбордом и переключаться Alt+Tab на слайдах 11–12.
- [ ] (по желанию) `schedule_install.bat` — тогда в журнале будут запуски с пометкой `schedule`,
      это хорошее доказательство автоматизации. Компьютер при этом должен быть включён.

**За 10 минут до защиты:**
- [ ] Ноутбук на зарядке, интернет есть (демо сбоев и обновление ходят в сеть).
- [ ] `run.bat` (обновление ~30 секунд) или `run.bat skip`, если интернет ненадёжный.
- [ ] Открыть страницу «Прогноз», масштаб браузера 90–100%.
- [ ] Закрыть лишние вкладки и уведомления.

**Демо устойчивости** (страница «Журнал и качество» → «Демо-режим сбоев»):
- «лимит запросов (429)» → «Обновить данные сейчас» — **лучший вариант для показа**: видно ретраи,
  всё завершается успешно, ~30 секунд;
- «таймаут источников» — источники падают с ошибкой, остальные шаги отрабатывают, ~1 минута;
- «битый файл BTS» — перекачивает целый месяц (~1,5 минуты), файл уходит в карантин. Долго — лучше только рассказать.

После демо режим сам возвращается в «без сбоев».

## 6. Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| `'py' не является внутренней или внешней командой` | Python не установлен или без галочки PATH. Переустановить Python с галочкой «Add python.exe to PATH» |
| `run.bat` сразу закрывается | Запустить его из открытого терминала (`cd` в папку → `run.bat`), чтобы увидеть ошибку |
| Ошибки при `pip install` | Проверить интернет; удалить папку `.venv` и запустить `run.bat` снова |
| BTS: `SourceError ... попыток: 4` / таймауты | Сайт `transtats.bts.gov` бывает недоступен из РФ: включить VPN и запустить снова. Либо скачать ZIP вручную (см. ниже) |
| METAR: `HTTP 503` | IEM ограничивает частоту запросов — подождать пару минут, запустить снова. Догрузится только недостающее |
| Порт занят: `Port 8501 is already in use` | Дашборд уже запущен в другом окне — закрыть его, или `.venv\Scripts\python -m streamlit run app.py --server.port 8502` |
| Браузер открылся раньше дашборда, «не удаётся получить доступ к сайту» | Подождать пару секунд и обновить страницу (F5) |
| На странице «Модель ещё не обучалась» | Нет данных: запустить `update.bat` или кнопку «Обновить данные сейчас» |
| Странные символы в терминале | Не влияет на работу. В новом окне `cmd` перед командами выполнить `chcp 65001` |

**Ручная загрузка BTS** (если скрипт не может скачать):
1. Открыть в браузере (с VPN) ссылку вида
   `https://transtats.bts.gov/PREZIP/On_Time_Reporting_Carrier_On_Time_Performance_1987_present_2026_8.zip`
   (год и месяц без ведущего нуля в конце).
2. Страница «Данные» → «Импорт файла BTS вручную» → выбрать ZIP → «Импортировать».
