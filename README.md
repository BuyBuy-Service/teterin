# AeroPulse — задержки рейсов аэропорта Chicago O'Hare (ORD)

Проектная работа по дисциплине «Визуализация данных» (НИТУ МИСИС), тема №7 «Гражданская авиация»:
прогноз числа рейсов и доли задержек в аэропорту.

**Команда:** Харлашкина А.В., Селиванова А.К., Козлов В.Н.

## Части проекта

| Часть | Ответственный | Код | Страница дашборда |
|---|---|---|---|
| A. Задержки: сбор BTS, журнал загрузок, инкрементальность, качество данных, редактирование | Харлашкина А.В. | `sources/bts.py`, `pipeline.py`, `dq.py` | «Данные», «Журнал и качество» |
| B. Погода: METAR (слабоструктурированные данные), прогноз Open-Meteo, связь погоды и задержек | Селиванова А.К. | `sources/metar.py`, `sources/openmeteo.py`, `metar_parser.py` | «Погода и задержки» |
| C. Прогноз: витрина, модель, оценка точности, прогноз на 7 дней | Козлов В.Н. | `marts.py`, `model.py` | «Прогноз» |

## Стек

Python 3.14, SQLite, pandas, scikit-learn, Streamlit + Plotly. Без серверной инфраструктуры:
вся система запускается одной командой на любом ноутбуке.

## Запуск

```bat
py -3.14 -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python db.py          :: создать схему
```

Источники описаны в [docs/sources.md](docs/sources.md).
