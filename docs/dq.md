## Защиты на этапе загрузки (не в dq.py, а в загрузчиках)

- битый ZIP → файл в `data/raw/quarantine`, запуск `failed`, данные не тронуты;
- дубли ключа в исходном CSV отбрасываются и считаются в `rows_skipped`;
- ответ источника неожиданного формата (не CSV у IEM, нет полей у Open-Meteo) → понятная ошибка в журнале;
- недопустимые параметры (месяц BTS в будущем, METAR из будущего, кривой формат даты) → отказ с объяснением;
- ручные правки валидируются (тип, диапазон, формат времени `hhmm`), флаг DepDel15 пересчитывается из минут.
